# AdLint 3.4.0 - Innoventix fork

AdLint is a source code static analyzer for C. This maintained fork is based on
AdLint 3.2.14, originally written by Yutaka Yanoh and OGIS-RI Co.,Ltd.

Maintained by **Innoventix**, with Pieter Marx as the contact:
<pietermarx@innoventix.co.za>.

Version: **3.4.0 (2026-11-19)**. Requires Ruby 1.9.3 or later; this working
version has been tested on Ruby 1.9.3p125. See [NEWS](NEWS) for changed metric
definitions and [ChangeLog](ChangeLog) for the change record.

* [Innoventix fork repository](https://github.com/Pieter-Marx-Innoventix/adlint)
* [Building the gem](BUILDING_ADLINT_GEM.md)
* English and Japanese user guides: included under `share/doc` in the built gem.
* [Original AdLint 3.2.14 package](https://rubygems.org/gems/adlint/versions/3.2.14)
