# AdLint 3.4.0 - Innoventix fork

AdLint is a source code static analyzer for C. This maintained fork is based on
AdLint 3.2.14, originally written by Yutaka Yanoh and OGIS-RI Co.,Ltd.

Maintained by **Innoventix**, with Pieter Marx as the contact:
<pietermarx@innoventix.co.za>.

Version: **3.4.0 (2026-11-19)**. Tested on Windows with 32-bit Ruby
**1.9.3p125**. The gem's minimum-version setting is `>= 1.9.3`; compatibility
with newer Ruby versions, other platforms and Bundler has not been verified
for this fork. See [NEWS](NEWS) and [ChangeLog](ChangeLog) for changes.

Install a verified local fork package with `gem install --local
path\to\adlint-3.4.0.gem --no-ri --no-rdoc`. See [INSTALL](INSTALL) for details.
The reporting version alone does not establish publication or identify an
exact build: retain the source revision and the package SHA-256.
